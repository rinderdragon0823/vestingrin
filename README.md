# VESTIGRIN

記憶された動きについての、静かなインタラクティブ習作。

暗闇に6体の淡い生命体が漂っている。あなたの動きを見て、その断片を記憶し、あなたが手を離すと不完全になぞり返す。長く付き合うほど、彼らはあなたになつく。

## 眺め方

- **ゆっくり動かす** — 生命体が気づいて記憶できる淡い軌跡が残る。
- **淡い図形をなぞる** — 点線の弧・環・波がときどき現れる。なぞると近くの個体にその形を教えられる。
- **押し続ける** — 彼らを手元に集める。
- **静止する** — 落ち着いて、覚えた動きを再生し始める。

静かなゲーム：6体全員に「覚えてもらう」ことが目標。覚えるには深いimprintと2つ以上の保持形状が要り、ゆっくり薄れるので維持が必要。図形を教える前に押し続けて近くに集めておくと効率が良い。右上のledgerは「n/6 know you」と進み、覚えた個体は細い環をまとう。6体全員が覚えるとしばらく一斉に動く。得点も勝敗画面もない。タッチはマウスと同じ操作。

## 挙動について

- 生まれたての個体は鈍い：ほとんど追わず、大きく揺らぎ、一度に1つの形しか保てない。新しい形を覚えると古い方は忘れる。
- 個体が動きに近いほど長期のimprintが溜まり、ゆっくり減衰する。育つほど強く追い、速く動き、揺らぎが減り、線を正確になぞり、頭部の触手が伸び、最大3つの形を保てる。
- 記憶の成立は目に見える：描いた場所に軌跡が1.6秒ほどなぞり直され、覚えた個体に細い輪が開き、隅のledgerに「kept your trace」と出る。`last`行は次の出来事まで残る。
- 各頭部の細弧はimprintを空から満ちるまで示し、環が閉じれば「覚えた」印。リハーサル中は記憶原本が破線のゴースト（始点 tick 付き）で出て、身体は生の不完全な再現を描く — imprintが低い間は両者が目に見えて食い違い、学習で一致していく。リハーサルを重ねた古いゴーストほど僅かに読みやすい。
- そのブラウザで最初の保持だけは「kept — now stay still」、最初のリハーサルだけは「replaying what it kept」と出て、以後は簡潔な表記に戻る。常駐チュートリアルは出さない。
- リハーサルが一巡するたび、記憶形状はその個体の湾曲に沿って僅かに撓む。古い記憶は同一再生ではなく数分かけて漂う。長く放置すると群れは緩く集まる。
- 個体ごとに tempo・curl・dwell が違う：漂う者、留まる者。
- ポインタの大ジャンプでは軌跡を画面越しに縫わず新規扱いにする。指の離→触やマウスの素早い移動が直線を教え込むことはない。

## 操作

- 左上の `menu` 文字から pause・reset・guide・export・import・share を開く。ガイドは選択か `Escape` で閉じる。
- キー：`space` 停止/再開、`h` ガイド、`e` 書き出し、`s` 共有、`r` リセット（2度押しで確定）。
- タッチはマウスと同等。メニューとボタンは指で触れる大きさ。

## 記憶：保存・ファイル・リンク

- 群れは数秒ごととページ離脱時にこのブラウザのlocalStorageへ自動保存され、開き直すと続きから始まる。位置・図形・セッション計時は保存対象外 — imprint・個体特性・記憶形状が対象。
- `export` は `vestigrin-memory.json` のDLとクリップボードコピー、`import` はその読み戻し。
- `share` は簡略化コロニーを運ぶリンクをコピーする（形状を間引き・値を丸め）。約1500字を超える場合はJSON全文のコピーに切り替わり、ledgerがそう告げる。

## 技術構成

- GitHub Pages用の静的ページ：`index.html`・`style.css`・`vestigrin.js`。依存なし、ビルド不要。アセット参照はすべて相対、共有リンクは現在のアドレスから組み立てるのでサブパス配下でも動く。
- 単一2Dキャンバス＋緩慢フェードによる自然な残像描画。身体は骨白の細い先細り spine ポリライン、1体のみ錆色。
- 動きは重ね合わせ正弦の漂流＋ポインタ牽引＋記憶再生。ポインタ軌跡は短い時刻付きバッファで保持。
- 配色は近黒 `#0b0b0a`・骨 `#e6dfcf`・くすんだ錆色に限定。グラデ・発光・画像素材なし。
